# 銘傳大學《人工智慧概論》期中線上考試系統 (GitHub Pages 部署與考題指南) 本指南提供一套專為 **GitHub Pages** 免費靜態託管設計的線上期中考題與批改系統設計。本系統依據來源文件 **《(網路出題)2026.11(上)公事系人工智慧概論(期中)試題.docx》** 的完整內容建置，收錄全部 20 道單選考題與標準解答（每題 5 分，滿分 100 分）。 --- ## 一、 系統架構與雙視角設計 本系統採單頁式網頁應用程式 (Single-Page Application) 架構，無需後端伺服器即可於 GitHub Pages 上發布： 1. **學生端視角 (Student View)** - **題目展示**：學生開啟網頁後，僅能閱讀 20 道題目與選項，無法預覽解答與分數。 - **身份輸入**：學生需輸入「學號」與「姓名」後始可開始作答。 - **送出機制**：作答完畢點擊「送出考卷」，系統自動產生「答題憑證代碼」，學生可複製傳送給教師登記。 2. **教師端視角與批改功能 (Teacher View)** - **模式切換**：點擊切換至教師批改介面。 - **自動批改**：教師貼上學生送出的答題代碼，系統自動比對內建標準答案鍵，計算總分（滿分 100 分）。 - **成績明細**：呈現學生學號、姓名、總得分與答對題數明細。 --- ## 二、 考題內容與標準答案鍵 (全 20 題) 依據考題文件，20 道考題解答如下： | 題號 | 題目關鍵字 | 標準答案 | | :---: | :--- | :---: | | **1** | 人工智慧（AI）定義 | **B** | | **2** | 智慧包含理解情境與適應變化 | **A** | | **3** | 天生條件與後天經驗交互作用 | **C** | | **4** | 記憶三步驟（編碼、儲存、提取） | **B** | | **5** | 考試想起內容屬「提取」 | **C** | | **6** | 神經可塑性 | **B** | | **7** | 機器學習辨識貓狗 | **A** | | **8** | AI 不是魔法（來自資料與演算法） | **B** | | **9** | 亞里士多德（三段論與邏輯推理） | **B** | | **10** | 安提基特拉儀（古代天文計算機） | **B** | | **11** | 艾倫・圖靈（機器能思考嗎） | **A** | | **12** | 圖靈測試（對話像人類） | **B** | | **13** | 達特茅斯會議 (1956年) | **A** | | **14** | 傳統規則式 AI | **B** | | **15** | AI 包含 機器學習 包含 深度學習 | **C** | | **16** | 機器學習從資料中學習規律 | **B** | | **17** | 深度學習（多層神經網路） | **A** | | **18** | 生成式 AI（產生新內容） | **C** | | **19** | 自然語言處理 NLP（翻譯與摘要） | **B** | | **20** | 電腦視覺（人臉辨識） | **B** | --- ## 三、 GitHub Pages 部署步驟教學 1. **建立 GitHub Repository** - 於 GitHub 新建一個名稱為 `ai-exam` 的公開 Repository (Public)。 2. **上傳網頁主檔** - 將包含題目與自動批改邏輯的 `index.html` 網頁檔上傳至主目錄。 3. **開啟 GitHub Pages 發布** - 點選 **Settings** -> **Pages**，將 Branch 設為 `main` 分支並儲存。 - 發布後即可取得學生在線作答的專屬網址。
